# IronPeak Fitness Club

Proyecto académico para la gestión de un gimnasio.

## Estado actual

En esta entrega la implementación funcional todavía no está desarrollada. Este repositorio contiene la documentación técnica y funcional actualizada y una estructura base de desarrollo para comenzar la implementación.

## Propuesta tecnológica

- Lenguaje: C#
- Plataforma: .NET 8
- Interfaz: Windows Forms
- IDE: Visual Studio
- Base de datos: SQL Server
- Control de versiones: Git y GitHub
- Integración continua: GitHub Actions

## Arquitectura propuesta

Se trabajará con una separación por capas:

- Presentación: interfaz Windows Forms.
- Negocio: reglas y lógica del sistema.
- Datos: acceso a SQL Server.
- Base de datos: almacenamiento de la información.

## Módulos principales

1. Gestión de pagos.
2. Gestión de horarios y eventos.
3. Gestión de planes nutricionales.
4. Gestión de rutinas.
