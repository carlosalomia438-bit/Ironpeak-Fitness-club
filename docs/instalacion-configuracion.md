# Instalación y configuración

## Estado de la implementación

La solución funcional todavía no está terminada. Por esta razón, las siguientes instrucciones corresponden al entorno previsto para el desarrollo.

## Requisitos previos

- Windows 10/11.
- Visual Studio 2022 o compatible con .NET 8.
- .NET 8 SDK.
- SQL Server.
- Git.
- Una cuenta de GitHub para clonar el repositorio.

## Preparación prevista

1. Clonar el repositorio.
2. Abrir `src/IronPeak.sln` en Visual Studio.
3. Restaurar las dependencias de .NET.
4. Configurar la cadena de conexión de SQL Server cuando la base de datos sea implementada.
5. Ejecutar la solución.

## Base de datos

La base de datos SQL Server y su script de creación se incorporarán durante la etapa de implementación. En esta entrega no se afirma que la base de datos ya esté creada.

## Ejecución

La aplicación base podrá compilarse desde Visual Studio. Las funciones del negocio se incorporarán progresivamente.

## Nota

Un tercero podrá seguir estas instrucciones para preparar el entorno, pero la ejecución completa de las funcionalidades dependerá de las etapas posteriores de desarrollo.
