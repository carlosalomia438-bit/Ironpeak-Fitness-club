# Documentación funcional

## Estado

La documentación funcional describe cómo se espera que funcione el sistema. En esta entrega todavía no existen pantallas funcionales implementadas, por lo que no se incluyen capturas reales.

## Flujo 1: Registrar un pago

1. El usuario autorizado ingresa al módulo de pagos.
2. Busca o selecciona al miembro.
3. Registra los datos del pago.
4. El sistema valida la información.
5. Se guarda el registro.
6. El sistema muestra la confirmación.

**Condición:** el usuario debe tener permisos para registrar pagos.

**Objetivo:** realizar el registro de manera sencilla, con un flujo diseñado para completarse en menos de 2 minutos.

## Flujo 2: Consultar horarios y eventos

1. El usuario ingresa al módulo de horarios.
2. Consulta las actividades disponibles.
3. Selecciona el horario o evento que desea revisar.
4. El sistema muestra la información correspondiente.

## Flujo 3: Consultar plan nutricional

1. El usuario autorizado selecciona un miembro.
2. Ingresa al apartado de plan nutricional.
3. Consulta el plan asociado.
4. El sistema muestra la información disponible.

## Flujo 4: Consultar rutina

1. El usuario autorizado selecciona un miembro.
2. Ingresa al apartado de rutina.
3. Consulta la rutina asociada.
4. El sistema muestra la información disponible.

## Evidencias

Las capturas de pantalla se agregarán cuando las interfaces sean implementadas. No se presentan capturas inventadas en esta entrega.
