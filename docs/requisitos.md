# Requisitos del sistema

## 1. Alcance actual

IronPeak Fitness Club se plantea como una aplicación de escritorio para apoyar la gestión de un gimnasio. La solución contempla tres áreas principales identificadas en la entrega anterior: pagos, horarios/eventos y planes nutricionales/rutinas.

Los valores numéricos usados en el planteamiento del problema son estimaciones provenientes del levantamiento previo y no corresponden a una auditoría contable.

## 2. Requisitos funcionales

### RF-01. Registro de pagos
El sistema permitirá registrar los pagos realizados por los miembros y consultar su información.

### RF-02. Registro de pagos en menos de 2 minutos
El flujo de registro de un pago deberá estar diseñado para poder completarse en menos de 2 minutos bajo condiciones normales de uso.

### RF-03. Gestión de horarios y eventos
El sistema permitirá registrar y consultar horarios y eventos del gimnasio.

### RF-04. Consulta de horarios
Los miembros podrán consultar la información disponible de horarios y eventos.

### RF-05. Gestión de planes nutricionales
El sistema permitirá registrar y consultar planes nutricionales asociados a los miembros.

### RF-06. Gestión de rutinas
El sistema permitirá registrar y consultar rutinas de entrenamiento asociadas a los miembros.

## 3. Requisitos no funcionales propuestos

### RNF-01. Usabilidad
La interfaz deberá ser sencilla y clara para los usuarios del gimnasio.

### RNF-02. Rendimiento
Las operaciones habituales deberán responder en tiempos razonables para el uso diario.

### RNF-03. Seguridad
El acceso a la información deberá estar controlado mediante usuarios y permisos definidos durante la implementación.

### RNF-04. Mantenibilidad
El código se organizará por capas para facilitar su mantenimiento y futuras modificaciones.

### RNF-05. Compatibilidad
La aplicación estará orientada a equipos Windows compatibles con .NET 8 y Windows Forms.

> Estos requisitos describen el alcance planificado. No deben interpretarse como funcionalidades ya implementadas.
